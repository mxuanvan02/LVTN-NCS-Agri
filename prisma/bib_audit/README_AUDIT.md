# PRISMA audit package

This folder contains the verification package for the thesis systematic review on
Networked Control Systems in smart agriculture.

## Purpose

The audit package allows a reviewer to trace every reported PRISMA number back to
machine-readable files. The flow reported in the thesis is:

`627 raw records -> 424 unique sources -> 187 after title/abstract screening -> 123 eligibility candidates -> 64 verified core sources`

Two points that earlier versions of this README stated incorrectly, now corrected:

1. **The final reference set is 64 sources, not 120.** The 187 sources entering
   eligibility consist of 64 pre-existing reference sources plus 123 new
   candidates. Of those 123 candidates, 67 were excluded outright and 56 met the
   PNCE criteria *at abstract/metadata level only*. Cross-checking those 56
   candidates against the reference set found three duplicate works
   (FT081=S37, FT107=S47, FT113=S45); the other 53 remain on hold. This overlap
   check does not establish full-text PNCE verification for the 64-source set.
   The reference set has verified bibliographic/metadata identity and an existing
   coding table; field-level full-text status and RoB are recorded separately in
   `rob_grade_audit_log.csv`. The earlier "120 = 64 + 56" figure counted
   candidates that were never added to the analytical set.
2. **The 627 raw records are not the output of the 10 OpenAlex queries.** They
   are a merged identification set across three channels. The queries returned
   246 records; see `raw_by_source_channel` in the query log for the split.

The tools and AI-assisted steps were used only for search support, metadata
normalization, duplicate detection, extraction of traceable evidence, table
generation, and consistency checks. They were not used as scientific evidence and
did not replace the author's final academic judgement.

## Core set provenance (read this before assessing selection bias)

No core source originates from queries Q1-Q10: every row with
`pnce_status=included_core` in `prisma_raw_all_sources_rebuilt.csv` carries
`query_id=CORE68` and `source_channel=existing_core68`. The core set was built
first, through in-depth reading, and the systematic queries were then run as a
**coverage check**.

Read in both directions: the 246 query results added no new source meeting all
four PNCE components, which is evidence of reasonable coverage; but because the
core set predates the queries, the review cannot claim to have eliminated
selection bias through an a priori query protocol. The thesis states this
explicitly in Chapter 2 (§Nguồn thông tin và chiến lược tìm kiếm) rather than
presenting the pipeline in reverse order.

## Main files

- `prisma_rebuilt_query_log.json`: query log, per-query counts, source-channel split.
- `prisma_raw_all_sources_rebuilt.csv`: all raw records before deduplication.
- `prisma_deduplication_evidence.csv`: duplicate/fragment evidence and retained record IDs.
- `prisma_unique_screening_rebuilt.csv`: unique source list with screening status.
- `prisma_screening_decisions_evidence.csv`: title/abstract screening decisions and reason codes.
- `prisma_fulltext_eligibility_queue.csv`: the 187 sources entering eligibility, split by status.
- `prisma_fulltext_final_decisions.csv`: final eligibility decision for the 123 candidates.
- `prisma_step_evidence_map.csv`: mapping from PRISMA steps to evidence files.
- `core68_source_audit_trail.csv`: core set audit trail; four duplicate DOI/title entries were resolved, leaving 64 unique core sources.
- `lvtn_68_coding_per_paper.csv`: current PNCE classification fields; confidence columns describe classification confidence, not study quality.
- `fulltext_availability_inventory.csv`: OA/full-text discovery and completed-review status.
- `rob_grade_audit_log.csv`: record role, evidence tier, locator-backed adapted RoB D1--D6 judgements, and applicability.
- `grade_claim_audit.csv`: provisional claim-level adapted-GRADE decisions.
- `build_rob_grade_audit.py` and `apply_fulltext_rob_reviews.py`: regenerate the conservative base log and reapply completed full-text reviews.
- `rob_grade_audit_log.csv`: 64-row evidence-tier and adapted RoB audit log. Thirty-four sources have locator-backed full-text review; all unreviewed method-dependent domains remain `unclear/not_assessable`.
- `pnce_recode/pnce_fulltext_recode.csv`: 12-variable PNCE recoding of the 34 reviewed sources, with a per-field locator, verbatim quote, and `coding_basis` (`rule`, `adjudicated`, or `absent`). Nine fields were corrected by hand after keyword rules misfired; see `pnce_recode/manual_overrides.json`.
- `fulltext_retrieval_log.csv` and `fulltext_retrieval_results.json`: per-route retrieval attempt log (OpenAlex/Unpaywall locations, DOAJ, Europe PMC, Semantic Scholar, OpenAIRE/CORE, arXiv, publisher mirrors) with HTTP outcome per attempt.
- `fulltext_audit_batches/`: the six read-only batch audit reports for the remaining 54 sources.
- `fetch_remaining_fulltext.py`, `fetch_remaining_fulltext_pass2.py`, `import_remaining_fulltext_audits.py`, `apply_pass2_fulltext_reviews.py`: retrieval and import scripts that reproduce the current audit state.
- `fulltext_availability_inventory.csv`: OA/landing-page availability inventory; URL discovery does not count as review.
- `grade_claim_audit.csv`: provisional claim-level adapted-GRADE log for three thesis claims.
- `build_rob_grade_audit.py`: regenerates the metadata-level audit and availability inventory.
- `apply_fulltext_rob_reviews.py`: reapplies the ten completed locator-backed reviews.
- `regen_ch3_tables.py`: regenerates Chapter 3 counts and cite lists from the coding file.

Note: `prisma_fulltext_final_summary.json`, `prisma_fulltext_review_summary.json`,
and `prisma_screening_audit_summary.csv` were removed in an earlier cleanup round
because they recorded superseded totals (120, 56, 54, and a conflicting
135 -> 68 flow). Do not reintroduce those numbers.

## Search strategy summary

The search used adaptive query expansion around the PNCE framework:

- P -- Plant/application: irrigation, greenhouse, fertigation, hydroponic, soil moisture.
- N -- Network: LoRaWAN, ZigBee, WiFi, NB-IoT, wireless sensor network, cloud, edge.
- C -- Control: event-triggered control, self-triggered control, model predictive control, fuzzy control, PID, reinforcement learning.
- E -- Evaluation: experiment, simulation, field test, energy saving, water saving, RMSE, IAE, packet loss, delay.

The principal academic metadata sources were OpenAlex, Crossref, Unpaywall, DOI
landing pages, and locally curated thesis source lists. Query strings and counts
are recorded in `prisma_rebuilt_query_log.json` and in the thesis appendix.

## Tool accountability

| Stage | Tool support | Human responsibility |
| --- | --- | --- |
| Search query design | Keyword expansion and metadata APIs | Define scope, timeframe, PNCE criteria, and final query families. |
| Metadata collection | OpenAlex/Crossref/Unpaywall/DOI landing pages | Check whether records are relevant and academically traceable. |
| Deduplication | Python scripts | Review matching rules and ambiguous duplicates. |
| Screening | Python scripts and PNCE reason codes | Interpret inclusion/exclusion criteria and accept final decisions. |
| Eligibility | Full-text/metadata retrieval scripts | Apply the conservative rule when evidence is insufficient. |
| Evidence verification | Cross-check scripts against the core corpus | Decide the evidence threshold for the core set and apply it consistently. |
| Writing and tables | LaTeX, Python, AI-assisted consistency checks | Author the thesis, interpret findings, and take responsibility for claims. |

## Conservative rule

If a source did not provide enough accessible full text, abstract, DOI landing
page, or metadata evidence to verify the PNCE criteria, it was excluded at
eligibility rather than counted as included. A second, stricter rule applies to
the core set: abstract- or metadata-level confirmation alone is not sufficient
for inclusion in the coded corpus. Both rules are intentionally conservative to
reduce the risk of over-claiming.
